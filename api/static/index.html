How it works

  1. Your questionplain English
  2. Dense + sparseBGE-large vectors (FAISS) and BM25 keywords
  3. FusionReciprocal Rank Fusion
  4. RerankMiniLM cross-encoder
  5. The momentbest segment per lecture, with timestamp

Lectures were transcribed with Whisper and slides read with Tesseract OCR. Segments follow slide changes detected from OCR similarity, and the full system reaches MRR 0.826 against 0.448 for a transcript-only, fixed-window baseline.
